Connecting…

Connect, monitor and run a test

This application controls your two ODrive Pro boards over USB. The test motor runs in speed control and the load motor applies opposing current through its torque-control input. No readings are generated when a board is disconnected.

  1. Commission each motor in the ODrive GUI. Complete calibration and check motor direction, limits and encoders. Configure the test board for velocity control with a velocity ramp, and the load board for torque control with a torque ramp. Save the settings. Close the GUI before connecting here.
  2. Open Board connections & states. Enter the two serial numbers, assign their physical roles, and save verified limits and the stop procedure. Connect only after the USB isolators are installed. Connecting reads board information; it does not start the motors.
  3. Open Motor monitoring. The left column is the test motor and the right column is the load motor. Check voltage, DC current, speed, position, torque estimates and board states. Unavailable signals stay blank.
  4. Choose a point in Test matrix. Select a pending point and click Run selected test. For a steady-state point, this applies the conditions, waits for settling, records for the planned duration and then commands both boards to IDLE. Run all selected tests queues the saved pending subset. The matrix shows running, recorded and blocked points. Changing feedback mode remains a manual commissioning step; unsupported sensorless startup pauses the queue.
  5. Review and export. Open Review & export data to inspect quality, select an analysis window and download the run ZIP with CSV, metadata and scripts.

Stop both · coast removes commanded torque and requests IDLE. It does not provide active braking or replace the rig's physical stop system. Enable motion only after this stop behaviour has been validated for your rig.

Sensorless starting from this website is currently unavailable because observer handover cannot yet be verified. An externally commissioned sensorless session can be monitored and manually recorded. The app does not change firmware, perform calibration, or silently switch encoder routing. Host plots are for monitoring. Steady-state high-rate buffers are saved automatically when required by the plan and the connected firmware supports the channels. Switching-ripple and synchronized angle measurements require separately verified bandwidth and timing.

The watchdog removes torque if communication stops. The test motor needs velocity control with a speed ramp; the load motor needs torque control with a torque ramp. Other blockers
Motor or encoder calibration: complete commissioning in the ODrive GUI, save it there, release its USB connections, then reconnect here. This tool does not run calibration or change feedback routing.
Watchdog timer expired: stop the rig, check USB communication and polling rate, then use Clear board errors on Connections. Clearing a fault does not fix its cause. Start remains a separate action.
Firmware or unavailable settings: check the firmware shown on Connections. Unsupported properties are rejected before applying changes. A partially applied update lists the settings that were verified; refresh and review before trying again.
