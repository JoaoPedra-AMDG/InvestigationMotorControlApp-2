Motor tuning

      
Script-managed settings
AllTests.py defines the velocity gains, ramp rates and current limits used during its configuration stage. Feedback bandwidth can be selected for each measured point. Automated PID tuning is not implemented in the working script, so this page does not issue independent tuning commands.
Change the settings in AllTests.py after checking the rig, then restart a test workflow to apply the script’s own configuration and verification sequence.
